# 🤖 AI Personal Assistant

An AI-powered Personal Assistant built using Python and Large Language Models (LLMs). The assistant can understand user queries, provide intelligent responses, perform tasks, and enhance productivity through natural language interactions.

## 🚀 Features

* Natural Language Conversations
* AI-Powered Responses
* Question Answering
* Productivity Assistance
* Easy-to-Use Interface
* Extensible Architecture

## 🛠️ Tech Stack

* Python
* OpenAI/Groq API
* LangChain
* FastAPI (Optional)
* HTML/CSS/JavaScript (Optional)

## 📂 Project Structure

```text
project/
│
├── main.py
├── assistant.py
├── requirements.txt
├── .env
└── README.md
```

## ⚙️ Installation

```bash
git clone https://github.com/your-username/AI-Personal-Assistant.git
cd AI-Personal-Assistant
pip install -r requirements.txt
```

## 🔑 Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key
GROQ_API_KEY=your_api_key
```

## ▶️ Usage

```bash
python main.py
```
